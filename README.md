# Atividade 09 - Outubro Rosa
    A proposta da atividade foi escolher um dos temas entre: Outubro rosa,
novembro azul e natal, e desenvolver um site utilizando todos os conteúdos revisados nas últimas aulas.
    A minha escolha foi outubro rosa, desenvolvi um site de três páginas sendo a primeira
o ínicio com uma breve explicação, a segunda com um enfoque maior no câncer de mama e a última um formulário pra incrições de possíveis interessados em apoiar a causa.
